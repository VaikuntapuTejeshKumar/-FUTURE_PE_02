# AI Cricket UGC Ad Generator

## Prompt Engineering Task 2

An AI-powered Prompt Engineering project for creating a complete UGC advertising content pack for a cricket product.

---

## 🏏 Project Overview

This project demonstrates how Prompt Engineering can be used to transform verified product information into a complete UGC-style advertising campaign.

The selected product is:

**SG Thunder Striker English Willow Cricket Bat**

The project focuses on creating authentic, relatable and platform-specific advertising content for young and amateur cricket players.

| Category | Details |

| Campaign Sector | Cricket |

---

## 🎯 Project Objective

The objective of this project is to demonstrate a complete Prompt Engineering workflow for creating UGC advertising content.

The workflow includes:

1. Product Research
2. Target Audience Analysis
3. Customer Problem Identification
4. Master UGC Advertisement Creation
5. Hook Generation
6. UGC Script Creation
7. Tone Variation
8. Platform Adaptation
9. CTA Generation
10. Caption Generation
11. Final UGC Advertising Content Pack
